# Illustrated terrain tiles

Drop generated tile art in this folder as **`<terrain>-<n>.webp`** (1-based), then
bump the matching number in `TILE_VARIANTS` in
[`src/game/boardArt.ts`](../../src/game/boardArt.ts). Example: after creating
`forest-1.webp` through `forest-4.webp`, set `forest: 4`.

Terrains: `fields` (grain), `forest` (lumber), `pasture` (wool), `hills` (brick),
`mountains` (ore), `desert`.

## How the art is used (read before generating)

- The renderer draws each image into a **square box of side `2·SIZE`** centred on
  the hex, then **hex-clips** it with `preserveAspectRatio="xMidYMid slice"`
  (cover). So:
  - Author **square** images (1:1). No hexagon alpha / transparent corners needed
    — the corners get clipped away.
  - A flat procedural colour is always drawn **underneath**, so a missing or
    slow-loading file just shows the terrain colour — never a hole. Edges get a
    crisp vector rim on top regardless.
  - **A round number-token chip is overlaid dead-centre on every tile in-game,
    covering the central ~33% of the image width** (measured against the actual
    render code, not approximate). Anything drawn there — a sheep, a wheat
    sheaf, a peak — gets hidden behind it. Every prompt below already builds in
    a calm, uncluttered centre for this reason — don't drop that clause if you
    tweak the wording.
- Recommended export: **512×512 WebP**, ~80–90% quality.

## Per-terrain prompts — fully assembled, paste as-is

Each block below is a complete, ready-to-paste prompt for one file. They all
share the same style/lighting/centre-clear preamble (for cohesion across the
whole board) and differ only in the scene description at the end.
